# Demonstração do Painel CBS 2027

Página de demonstração do estudo de reforma tributária da **Portes
Contabilidade**. Mostra, para uma empresa de exemplo, o que se paga hoje de
PIS/COFINS, o que passa a ser devido de CBS em 2027, quanto disso volta como
crédito das compras e quanto de preço seria preciso repassar para não perder
resultado.

## Importante

**Eleven Assinatura Ltda é uma empresa fictícia.** Clientes, fornecedores,
faturamento e documentos foram gerados para a demonstração. Todos os CNPJ e
CPF da base têm dígito verificador inválido de propósito, para que nenhum
corresponda a empresa que exista. Nenhum dado de cliente real aparece aqui.

Perfil da empresa de exemplo: Lucro Real com PIS/COFINS cumulativo de 3,65%
(art. 10, XXV c/c art. 15, V da Lei 10.833/2003, serviços de informática),
ISS de 2,9% e sem desoneração da folha.

A alíquota de CBS usada é a de referência estimada de 9,3%. O percentual
ainda será fixado por Resolução do Senado Federal.

## Estrutura

É uma página só, sem backend e sem banco. Os dados vivem embutidos no próprio
arquivo. Precisa de internet apenas para carregar a biblioteca de gráficos.

`index.html` é gerado por script, nunca editado à mão. O código de geração
fica fora deste repositório.
